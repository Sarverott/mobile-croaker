MOBILE CROAKER 🐸⚡

An autonomous agentic mobile workspace node transforming Android smartphones into orchestrated AI execution environments with zero-crash 4-tier accessibility fallbacks, declarative YAML workflows, and an embedded Model Context Protocol (MCP) tool server.

Org: Inceptorium Apokryf • Architect: Sett Sarverott A.A.B. • Lead Engine: Merlin (Gemini 3.8 Flash) • Heritage: OpenClaw
⬇️ Download Release APK 📂 GitHub Repository 🛠️ BOS Framework

🛡️ 4-Tier Fallback Accessibility

Ensures autonomous agents never fail on dynamic or shifting mobile interfaces.

  • 1. View ID: viewIdResourceName match
  • 2. Fuzzy Text: Substring & exact text search
  • 3. Description: Accessibility label fallback
  • 4. Coordinates: ADB Shell & gesture dispatch

🔌 Model Context Protocol (MCP)

Native JSON-RPC 2.0 tool server letting Claude Desktop, Cursor, and Gemini drive the device.

  • device_info: Hardware & telemetry dump
  • get_ui_hierarchy: Active window accessibility tree
  • execute_action: 4-tier tap, type, swipe
  • run_shell_command: Non-root ADB bridge

📝 Codable YAML Scenarios

Workflows are declarative, versionable, and shareable across all RAUSON fleet nodes.

  • Declarative step sequences (click, input, swipe, wait)
  • Assertion checks (text_matches, package_equals)
  • Bi-directional YAML and JSON import/export
  • Integrated in-app visual scenario runner

🐍 Pyodide WebAssembly Sandbox

Isolated in-app scripting sandbox running Python 3.12 without external interpreters.

  • Pyodide WebAssembly core inside isolated WebView
  • Native window.MobileCroaker JS automation bridge
  • Base64-encoded execution isolating user scripts from XSS
  • Real-time telemetry and console log streaming

🌐 OpenAPI 3.0 REST Gateway

Embedded HTTP server (port 8080) for monitoring and external orchestration.

  • GET /api/v1/openapi.json: Full OpenAPI 3.0 spec
  • GET /api/v1/status: Real-time telemetry
  • GET /api/v1/hierarchy: Interactive view tree
  • GET /api/v1/stream/info: RTSP & MJPEG video links

📇 Multi-Format Phone Identity

Every node carries an autonomous identity profile (IDENTITY.md).

  • Standard Markdown format (IDENTITY.md)
  • YAML (identity.yaml) & JSON (identity.json)
  • TOML (identity.toml) & CSV (identity.csv)
  • Role, capabilities, fleet tags, and operator notes
