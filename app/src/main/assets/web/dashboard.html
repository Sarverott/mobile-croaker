Architecture inspired by project OpenClaw.

REST & OpenAPI Endpoints

  • Specification: GET /api/v1/openapi.json
  • Node Telemetry: GET /api/v1/status
  • UI Hierarchy Dump: GET /api/v1/hierarchy
  • Fallback Tap: POST /api/v1/action/tap
  • Text Input: POST /api/v1/action/type
  • Swipe Gesture: POST /api/v1/action/swipe
  • ADB Bridge Command: POST /api/v1/adb/shell
  • Video/RTSP Stream Info: GET /api/v1/stream/info

Model Context Protocol (MCP)

Autonomous tool server endpoint conforming to the Model Context Protocol JSON-RPC 2.0 specification.

Endpoint: POST /mcp

Exposed Tools: 

tools/list:
  - device_info
  - get_ui_hierarchy
  - execute_action
  - run_shell_command
  - capture_screen
